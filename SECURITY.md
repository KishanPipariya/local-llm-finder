# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the production
deployment. Older commits and third-party deployments are not supported.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** form in the repository's
Security tab. Do not include exploit details, malicious catalogue payloads, or
private user information in a public issue.

Include the affected route or module, reproduction steps, impact, and any safe
proof of concept. You should receive an acknowledgement within seven days. No
reward or disclosure deadline is promised, but good-faith reports will be
investigated and credited when desired.

For ordinary defects that do not create a security or privacy risk, use a public
GitHub issue instead.
