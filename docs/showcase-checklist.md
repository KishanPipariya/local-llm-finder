# Showcase checklist

Before a live demo or recording:

1. Open the deployed finder once shortly before presenting so its server-side catalogue cache can warm up.
2. Keep the checked-in [fixture-backed results screenshot](images/recommended-results.png) available as a fallback if the upstream public catalogue is temporarily unavailable.
3. Manually review each displayed installation path—Ollama, LM Studio, llama.cpp, and MLX—against the selected runtime and listed model file. This checklist does not claim that any installation command has been executed or verified.
